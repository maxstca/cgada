# Cash Grab Arena Data Viewer

This repository is used to maintain the Cash Grab Arena Data Viewer (CGADV), an R Shiny app for sharing data analysis and visualizations pertaining to [Cash Grab Arena](https://github.com/HazilTheNut/cashgrab), a PvP-centric Minecraft minigame.

[Click here to visit the CGADV.](https://maxstca-cgada.share.connect.posit.cloud/)
